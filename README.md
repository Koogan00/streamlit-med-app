# 🩺 MedAssist

An AI-powered pediatric medication dosage calculator built with Streamlit.

This application helps healthcare professionals, pharmacists, medical students, and caregivers calculate accurate pediatric medication dosages safely and efficiently.

---

🚀 Features

✅ Pediatric dosage calculation based on body weight  
✅ Daily dose and single dose calculation  
✅ Liquid medication volume conversion  
✅ AI-powered clinical safety verification  
✅ Searchable medicine database  
✅ Calculation history tracking  
✅ CSV export support  
✅ Clean and responsive Streamlit interface

---

🧠 AI Safety Verification

The app includes an integrated AI clinical safety audit system using OpenRouter AI.

The AI pharmacist can:

- Verify calculated doses
- Compare with standard pediatric dosing
- Detect unusual dosing frequency
- Suggest safer dosing recommendations
- Identify discrepancies
